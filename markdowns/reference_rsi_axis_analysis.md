# 랜덤 박스 RSI: X/Y/Z 축별 초기 충격 분석

기록일: 2026-10-02. 다른 세션은 [목표·검사 아카이브](reference_rsi_archive.md)와
이 문서를 함께 읽는다. 목표는 **박스 크기를 최대한 유지하면서 쓸 만한 후반 RSI를
확보해 학습을 빠르게 하는 것**이다. 충격 감소 자체가 최종 목표는 아니다.

## 측정 조건과 해석 범위

- 사용자 실행 `impact_sweep`, seed 0, distill 정책 제어.
- X/Y 40~65cm, Z 25~55cm, 각 축 5cm 간격의 252개 조합.
- 원본 참조 모션의 후반 65~98%, 기존 1cm 기하 후보 필터 없음.
- 2048환경×32회 reset×20 control step. 기존 장면 배치 재추첨은 유지.
- 이 문서의 비율: **담당 박스의 첫 2 control step 중 최대 Δv >3m/s**.
- Δv는 선속도 벡터의 step 차이 크기다. 실패율·폭발 판정·학습 불가능 기준이 아니다.
- 축별 표는 해당 축의 값으로 표본을 묶고 다른 두 축·후반 시점을 합산했다.
  동일한 한 크기의 결과가 아니다. accepted 장면·동료·정책 반응 영향이 포함된다.
- 실제 학습 수렴 가속과 초기 학생에서의 안정성은 미검증이다.

## 후속 세션이 유지할 해석과 남은 확인

1. **기하 관통 검사 후보 0 ≠ 물리 초기화 불가능 ≠ 학습 불가능.**
2. 속도 진단 초과 0 ≠ 작은 튕김/급회전/파지 이탈 없음. 소표본 0도 안전 보장이 아니다.
3. 전체 축별 합산으로 샘플링 허용 범위를 확정하지 않는다. 정확한
   size×skill×motion×phase별 결과와 표본 수를 사용한다.
4. 첫 substep의 부위별 접촉·박스 수직 이동·각속도·정책 첫 action을 계측해 원인을 좁힌다.
   Y가 커지며 몸 쪽 접촉이 바뀐다는 설명은 아직 가설이다.
5. Δv≤1m/s 우선, 1~2m/s 조건부 허용은 미검증 제안이며 학습 설정에 적용하지 않았다.
6. 후보가 부족하면 같은 크기·skill의 시점을 앞쪽으로 확장하는 방향을 검토하고,
   작은 박스 재추첨이나 carry→loco 대체만으로 성능이 개선됐다고 주장하지 않는다.
7. 다른 seed/초기 학생 정책으로 확인한 뒤, 같은 크기·과제 분포의 비교 학습에서
   목표 성공률 도달 frame·벽시계 시간으로 수렴 가속을 판단한다.

PID 1184210 점검 당시에는 기존 RSI였다. 실제 허용 구간·박스 속도 0 초기화·
튕김 전이의 학습 저장 경로는 [실행 점검](rsi_pid1184210_audit.md)을 참조한다.
현재 실행 상태는 PID/설정을 다시 확인해야 하며 문서만으로 가정하지 않는다.
