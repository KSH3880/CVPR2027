# 3개 학습 실행의 성공률·edge bias 추이

기록 기준: **2026-10-03 16:22:14 KST**. PID 2978991(student RSI), 2734782(size RSI), 1099002(unified)의 당시 열린 TensorBoard 파일을 읽고 checkpoint를 CPU로 분석했다. 이 문서는 해당 시점의 고정 기록이며 새 hybrid 학습 결과를 포함하지 않는다.

## 지표와 비교 기준

- **Agent 종료 성공률:** 종료한 episode의 마지막 상태에서 agent의 모든 목표를 충족한 비율. HOLDING_AT/ON_TOP은 선행 HOLDING 자체보다 해당 task의 최종 목표 판정을 따른다.
- **Agent 성공 도달률:** 종료한 episode 안에서 agent가 한 번이라도 모든 목표를 충족한 비율. 성공 후 놓치거나 다른 상태로 끝나도 도달 성공으로 남는다.
- 성공률 표는 단일 epoch 값 대신 **직전 1000 epoch 구간의 완료 episode 가중 평균**이다. 모든 scene의 목표 owner가 2명이므로 logged completed_scenes로 가중하면 agent 분모와 비례한다. 1000행=1~1000, 2000행=1001~2000이다. 괄호의 Δ는 직전 1000 구간 대비 **퍼센트포인트(pp)**다.
- bias는 해당 **정확한 checkpoint epoch**에서 계산한다. source/relation/target type을 실제 task 방향으로 넣어 edge MLP→bias_projection을 통과시킨 attention logit 가산값이며, projection 파라미터 norm이 아니다. HOLDING H→O, AT O→G, ON_TOP O→O, SIT/CLIMB H→O를 사용한다.
- bias task 표의 각 셀은 **부호 평균 μ / RMS**다. 4 layer×2 head의 8개 값으로 계산했다. 평균만 보면 head 간 부호가 상쇄될 수 있어 RMS를 같이 기록한다. RMS가 커졌다고 성공률·최적화가 좋아졌다고 판정할 수는 없다.
- 학습 중 RSI·near start·박스 크기·task 분포가 서로 다르다. 아래는 학습 환경의 관측이며 동일 조건 loco 평가 성공률 비교가 아니다. `—`는 해당 구간/checkpoint가 아직 없어 비교하지 않았다는 뜻이다.
