# 4명 초과 혼합 환경의 그룹 스폰 규칙

## 적용 범위

2026-11-04 기준, 별도 진단 실행 경로에서 사용하는 규칙이다. 표준 학습·평가 wrapper의 기본 동작은 변경하지 않았다.

| 전체 사람 수 N | 사람 스폰 | 불필요한 distractor |
|---|---|---|
| N ≤ 4 | 기존 방식 유지 | 유지 |
| N > 4 | 기존 초기 위치 생성 후 그룹별 XY 평행 이동 | 물리 장면과 정책 관측에서 제외 |

공동 그룹 최대 인원은 4명이다. 단독 사람도 하나의 배치 그룹으로 센다. 전체 인원을 하나의 공동 그룹으로 만드는 평가가 아니라, 단독·여러 공동 그룹이 함께 있는 혼합 평가다.

## 생성 순서

1. 기존 혼합 규칙으로 사람들의 작업 그래프·공동 그룹·단독 행동을 샘플링한다.
2. 기존 원형 스폰 오프셋과 loco 모션 좌표로 사람들의 실제 초기 위치를 생성한다.
3. N > 4이면 각 그룹의 실제 중심을 계산하고, 새 원형 배치 자리까지 그룹 전원을 같은 XY 이동량으로 옮긴다.
4. 옮겨진 사람 위치를 기준으로 작업 상자와 목표를 기존 거리 규칙으로 샘플링한다.
5. 불필요한 distractor는 멀리 옮기고, ON_TOP 받침과 실제 작업 상자는 유지한다.
6. 기존 충돌·PUSH 경로 검사로 장면을 판정한다. 실패한 환경의 상자·목표 배치를 다시 시도하되 사람·그룹·행동은 유지한다.
7. 배치 통과 후 공동 상자의 담당 구역을 ordered로 할당한다. 관측에서 불필요한 distractor 슬롯을 제외한다.

상자·목표를 먼저 생성한 다음 통째로 옮기는 방식은 아니다. 기존 사람 배치를 만들고 사람 그룹만 먼저 이동한 뒤, 상자·목표를 생성한다.

## 작업 그래프와 행동

- 사람 순서를 무작위로 섞은 뒤 남은 사람에서 단독 또는 공동을 순차 선택한다.
- 공동 선택 확률은 기존 `coupled_probability=0.5`를 유지한다. 이는 매 선택의 확률이며 전체 사람의 50%가 공동이라는 뜻은 아니다.
- 공동을 선택하면 인원을 `2~min(4, 남은 인원)`에서 균등 샘플링한다. 남은 사람이 1명이면 단독이다.
- 공동 그룹의 행동은 PUSH다.
- 단독 행동 확률은 SIT 10%, CLIMB 15%, AT 25%, ON_TOP 20%, PUSH 30%다.
- 같은 공동 그룹끼리는 COUPLED, 다른 그룹 사이는 기존 NONE 관계를 유지한다. 그룹 이동을 이유로 다른 사람의 관측 토큰을 제거하거나 관계를 바꾸지 않는다.

예: 8명이 `공동4 + 공동2 + 단독1 + 단독1`이면 배치 그룹 수 G는 4개다.

## 기존 사람 위치와 그룹 이동

기존 사람 위치는 다음 구성이다.

```text
사람 초기 XY = 환경 위치 + 기존 N명 원형 슬롯 오프셋 + loco 모션 root XY
```

기존 원형 슬롯 반경은 2.5m다. loco 모션의 XY 변위도 그대로 남긴다. 그룹원을 새 슬롯에서 다시 뽑거나, 그룹 내부 간격을 압축하지 않는다.

그룹 g에 속한 사람들의 실제 초기 XY 평균을 중심 c_g로 계산한다. 목표 배치 중심 t_g까지의 이동량을 모든 그룹원에게 동일하게 적용한다.

```text
그룹 이동량 Δ_g = t_g - c_g
이동 후 사람 위치 = 기존 사람 위치 + Δ_g
```

kinematic body의 모든 부위에도 같은 XY 이동을 적용한다. 사람들 사이의 그룹 내부 상대 위치, root/body 높이·회전·선속도·각속도, DOF 자세·속도를 유지한다. 단독은 해당 사람 한 명이 그룹 중심이다.

각 N에서 기존에 뽑힌 내부 배치를 보존하는 방식이다. 기존 원형 슬롯이 N에 따라 달라지므로, 서로 다른 N의 그룹 내부 배치 분포까지 같아지는 것은 아니다.

## 그룹 중심 간 최소 간격 5m

5m는 원 반지름이나 모든 그룹의 이동 거리가 아니라, **이웃한 두 그룹 중심 사이의 직선 거리**다.

배치 그룹 수를 G, 최소 중심 간격을 d=5m로 두면 원 반경은 다음과 같다.

```text
G = 1: R = 0
G ≥ 2: R = d / [2 sin(π/G)]
```

| 배치 그룹 수 G | 원 반경 R | 이웃 그룹 중심 간격 |
|---:|---:|---:|
| 2 | 2.50m | 5m |
| 3 | 2.89m | 5m |
| 4 | 3.54m | 5m |
| 6 | 5.00m | 5m |
| 8 | 6.53m | 5m |
| 12 | 9.66m | 5m |
| 16 | 12.81m | 5m |

환경 원점을 중심으로 원 위에 G개의 자리를 같은 각도 간격으로 만든다. 원 전체의 기준 각도와 그룹-자리 대응을 무작위로 정한다. 원의 각도가 바뀌어도 사람의 자세·방향은 회전시키지 않고 XY 평행 이동만 한다.

예를 들어 그룹이 2개라면 반경 2.5m 원의 양 끝에 중심을 놓는다. 기존 그룹 중심이 어디에 있었는지에 따라 실제 이동 거리는 각각 달라진다.

## 상자·목표 거리 규칙

현재 ground/zerobg 설정의 거리 범위다. 거리 기준은 XY 평면의 중심 간 거리이며 상자 표면까지의 거리나 보행 경로 길이가 아니다.

| 작업 | 사람 → 작업 상자 | 작업 상자 → 목표 |
|---|---:|---:|
| 단독 SIT·CLIMB | 1~5m | 작업 상자 자체가 목적지 |
| 단독 AT·ON_TOP | 1~5m | 1~5m |
| 단독 PUSH | 2~5m | 2~5m |
| 공동 PUSH | 그룹원 모두 2~10m 조건 만족 | 2~5m |

공동 PUSH는 리더 주변에서 상자 후보를 생성한 뒤 모든 그룹원의 거리·상자 뒤쪽 위치 등 기존 조건을 검사한다. 공유 목표 방향은 기존 상자 전진 방향을 따른다. AT·ON_TOP 목표는 payload 기준으로 생성하며 ON_TOP 받침도 이 목표에 해당한다.

거리 후보 생성 수식과 허용 범위는 유지한다. 충돌·경로 검사 후 채택되는 최종 거리 분포가 N별로 완전히 같다고 보장하는 것은 아니다.

그룹 크기별 공유 상자 크기·질량·마찰, 행동별 물체와 지면 설정은 기존 환경 설정을 사용한다.

## Distractor와 관측

- 논리 물체 슬롯 수는 기본 M=2N을 유지한다.
- 각 사람의 작업 슬롯과 ON_TOP에 필요한 받침을 보존한다. 공유 상자의 개인 구역 토큰도 유지한다.
- 남는 불필요한 spare 물체만 물리 장면에서 약 1000m 이상 떨어진 주차 위치로 옮긴다.
- 해당 슬롯의 물체 특징과 pose 관측을 비활성 상태로 만들고 actor/critic encoder의 `object_valid`로 제외한다.
- 다른 그룹의 사람·실제 작업 물체·목표 토큰은 계속 제공한다. 공동 상대를 줄이는 keep3/shrink3는 적용하지 않는다.
- 카메라는 멀리 옮긴 distractor를 제외한 사람·필수 물체·목표를 기준으로 잡는다.

## 5m 선택 이유와 확인 범위

목적은 사람이 늘 때 발생하는 초기 배치 과밀을 완화하면서 그룹 내부 작업 조건을 보존하는 것이다. 5m는 고정 배치 하이퍼파라미터이며, 작업 영역을 완전히 분리하는 거리로 정의하지 않는다. 더 작은 간격을 비교하지 않았으므로 최소·최적 간격이라는 주장은 하지 않는다.

현재 `5m 그룹 이동 + 불필요한 distractor 제거`의 조합에서 다음을 확인했다.

| 인원 | 배치 표본 | 최종 통과 | 평균 시도 | 최대 시도 |
|---:|---|---:|---:|---:|
| 8 | 64환경·seed0 | 64/64 | 1.13회 | 4회 |
| 16 | 64환경·seed0 | 64/64 | 2.06회 | 26회 |

이 검증은 정책 rollout 0step이다. 별도로 4·8·16명 viewer 경로를 각 2씬×12step 실행하여 finite action·가중치 보존·매 씬 적용·4명 기존 동작·제거 토큰 영향 차단을 확인했다. GUI 실제 렌더링 및 정식 성공률은 이 짧은 검증의 범위에 포함하지 않는다.

추가로 Stage1 26k 고정 정책을 6·8·12·16명 각각 512환경×seed0/1/2로 평가했다. 총12회 모두1536/1536환경씩 배치 및1200step 평가를 완료했으며, 인원별 최대 배치 시도는4/5/9/52회였다. 재시도 한도는512회로 두었지만 이번 표본은 전부64회 이내에 통과했다. 큰 world XY의float32 검증 허용오차는0.5mm로 사용했다. 원래Stage1 encoder/head/RMS를 복원하고 Stage2 coordination을 우회했으며, CPU 재채점·제거 토큰 영향 차단·가중치/해시 검증을 통과했다. 이는 Stage1의 현재 혼합 환경 평가이며 원래900step 평가와 구분한다. [Stage1 결과](../../output_etc/check/stage1_26k_group_gap5_mixed512_20261104/report.md).
