# ma 계획

목표는 두 에이전트가 각자 물체를 운반하면서 공유 공간에서 충돌·간섭을 피하고,
최종적으로 space-time scheduling이 필요한 협동 태스크로 확장하는 것이다.

공통 실험 설계와 GPU 배치는 [전체 PLAN](PLAN.md), 완료 수치는
[AUTO_RESULTS](../experiments/AUTO_RESULTS_ma.md), 검토된 결론은
[EXPERIMENTS](../experiments/EXPERIMENTS_ma.md)를 따른다.

## 현재 기준 설정

| 항목 | 값 |
|---|---|
| 에이전트 | A=2, carry 전용 |
| 환경 | 2,048 env × 2 agents = 4,096 rows |
| 간격 | `envSpacing=5`, `MA_SEP=0` |
| 접촉 버퍼 | 4 M |
| 보상 | task 0.5 / disc 0.5 유지, `MA_C=0`, `MA_BETA=0` |
| 비교 | 같은 adapt 네트워크에서 teammate 토큰 zero vs live |

태스크·스킬과 에피소드 reset은 env 단위, 모션 시작은 agent 단위,
관측·보상·지표와 에이전트별 물체는 row 단위다.

## 활성 큐

사용자는 `tag`, 질문, 환경변수와 행 순서를 관리한다. 자동화는 3열 `상태/GPU`와 완료 행만 관리한다.
기본은 adapt Carry, live 토큰, seed 0, 3000 iter, A=2·2048 env,
spacing 5·contact 4M, `MA_SEP=0`, `c=0`, `β=0`이다. 4열에는 이 기본과 다른 값만 적는다.

## 판정 기준

- `train/adapt` 행은 학습 종료 뒤 512 env 최종 평가까지 성공해야 완료된다.
- 둘 다 성공률, makespan, 충돌 횟수·지속, deadlock, 에이전트별 이동 거리를 함께 본다.
- zero/live는 관측 크기와 네트워크 구조를 같게 유지한다.
- 보상 공유에서는 한쪽 이동 거리와 자기 보상 비중이 무너지는지 확인한다.
- 충돌 계수는 충돌 최소가 아니라 충돌 감소와 makespan 손실의 무릎으로 고른다.
- 인프라 측정은 `rc=0`과 함께 `warn=0`을 확인한다.
- **신호 문턱: Δ ≥ 0.05 만 신호로 본다.** 지금 대부분 시드 1개인데 학습 시드 변동이
  0.046 이라 그 아래는 "차이 없음"으로 처리한다 (F4 가 이 구분을 안 해 통째로 폐기됐다).
- **기준선** (지금 코드, env 2048, A=2): 상한 `0.9463`(간섭 없음) · 출발점 `0.8604`(sep0) ·
  근접 에피소드 `25.9 %` · 이동거리 `9.07 m`(A=1) · makespan 하한 `294` / 순차 `588`.
  **되찾아야 할 몫은 8.6 포인트다.**
- **2단계 승자 조건 (셋 다 만족해야 한다)**: ① `sr` 이 `t1_live` 대비 +0.05 이상,
  ② `t50` 이 588 쪽으로 안 밀림, ③ `pathA` 두 값의 비가 2 배 미만(게으름 없음).

## 결과별 다음 분기

| 결과 | 다음 행동 |
|---|---|
| live가 두 시드에서 zero보다 충돌·간섭을 줄임 | 입력 효과를 확정하고 충돌 계수 축으로 진행 |
| live와 zero가 같은 범위 | 입력보다 보상축을 먼저 탐색 |
| 시드 간 부호가 뒤집힘 | 우열을 보류하고 계측·학습 안정성을 먼저 확인 |
| 낮은 β에서 lazy-agent 발생 | 보상 공유 대신 `min_i(progress)` 분기 검토 |
| β=0.5에서만 lazy-agent 발생 | 그 아래 구간에서 β 확정 |
| **2단계 승자 조건을 만족하는 조합이 있음** | **그 설정 그대로 `MA_ITERS=15000`, 시드 2개로 장기런.** 3000 은 경향만 보는 길이 |
| 승자 조건을 만족하는 조합이 없음 | **장기런을 넣지 않는다.** 3단계(②①) 결과를 먼저 본다 — 안 되는 걸 오래 돌리면 시간만 태운다 |
| `t3_mkspn`(①) 단독이 실패 | 예상된 결과. **안 되는 걸 보인 것이 ②③를 쓰는 근거**가 된다. `t3_both`(②+①) 투입 |

## 열린 질문

1. teammate 입력만으로 암묵적 충돌 비용을 학습하는가.
2. 충돌 페널티 `c`가 필요한가, 물리적 실패 비용으로 충분한가.
3. 보상 공유 `β`가 협동을 만들면서 lazy-agent를 피할 수 있는가.
4. 입력 ablation과 경로 교차·병목 태스크로 언제 넘어갈 것인가.
