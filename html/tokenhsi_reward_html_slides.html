Directional Velocity Reward
TARGET DIRECTION · FINITE-DIFFERENCE VELOCITY · DOT PRODUCT
내적은 실제 속도 중에서 목표 방향으로 향하는 성분만 꺼낸다.
1 · 이전 step으로부터 실제 속도 계산 vt = (pt − pt−1) / dt
2 · 현재 위치에서 target으로 향하는 단위벡터 d̂ = normalize(targetxy − pt,xy)
3 · 내적으로 목표 방향 속도만 투영 vtoward = d̂Tvt,xy = ‖vt,xy‖cosθ
rvel = exp[−5(1.5 − vtoward)²]
Walkp = ph, target = pb
Transportp = pb, target = gb
속력 자체가 아니라 목표 방향으로 약 1.5 m/s 이동하는가를 보상한다.

7 / 8
Walk vs. Transport Gates
SAME DOT PRODUCT · DIFFERENT OVERRIDES

rwalk · humanoid → box

rwalk = 0.2 exp[−5(1.5 − vh→b)²]
  1. vh→b ≤ 0이면 velocity reward = 0
  2. root-box 수평 거리 < 0.5 m이면 velocity reward = 1
두 번째 조건이 나중에 실행되므로, box 가까이에서는 현재 속도와 무관하게 rwalk = 0.2.

rtransport · box → goal

rtransport = 0.2rbox_vel + 0.2e−10‖gb−pb‖² + Pbox_vel
  1. vb→g ≤ 0이면 velocity reward = 0
  2. pb,z ≤ hb/2 + 0.2이면 velocity reward = 0
  3. box-goal 수평 거리 < 0.5 m이면 velocity reward = 1
마지막 proximity override가 앞의 방향·높이 gate보다 나중에 적용된다. 3D near reward와 과속 penalty는 별도로 남는다.
두 reward는 같은 내적 구조를 쓰지만, transport에는 pickup 높이 gate와 3D 위치 reward가 추가된다.
