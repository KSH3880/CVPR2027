# 전달 메시지

안녕하세요! TokenHSI에 PUSH를 추가한 baseline 실험을 부탁드리려고 이관 폴더를 정리했습니다. 코드·설정·teacher/초기 student 가중치·모션 데이터와 AMP/RSI가 포함돼 있고, 설치와 실행 방법은 README.md에 적어두었습니다.

부탁드리는 목표는 **distillation 기반 방법 안에서 여러 방식을 검토해서, 기존 TokenHSI의 SIT/CARRY/CLIMB 성능 하락을 5% 이내로 유지하면서 우리 목표 영역 기준 PUSH final 성공률이 85%를 넘는 단일 student `.pth`를 만드는 것**입니다. TRAJ는 제외합니다. 현재 문서에서는 5%를 원본 teacher 대비 각 과제의 상대 하락률로 적어두었고, 기존 SIT/CARRY/CLIMB는 TokenHSI 원본 eval 기준으로 평가해 주세요. PUSH는 우리 목표 영역 기준으로 평가하고, **final을 목표 달성의 주 지표로, ever를 보조 지표로 함께 보고해 주세요. ever 결과도 발표 자료에 포함해 주시면 좋겠습니다.** 별도의 연속 유지 시간 조건은 추가하지 않습니다.

지금 구현한 distillation은 고정 teacher의 행동 분포를 KL로 보존하는 나이브한 방식이라, 구현과 설정이 적절한지도 먼저 점검 부탁드립니다. 이 방식에만 묶일 필요는 없고, distillation 범위 안에서 loss·가중치·스케줄·샘플링 등 여러 대안을 검토해 주시면 됩니다. PUSH의 환경·물성·reward·AMP·RSI와 평가 기준은 유지해 주세요.

최종적으로 전달받은 `.pth`는 저희가 직접 재평가하고 논문 결과 테이블에 넣을 예정입니다. 방법 자체도 논문에 설명할 수 있도록 변경 이유·방법·코드/설정·실험 이력과 seed별 평가 결과를 재현 가능하게 정리해 주시면 감사하겠습니다. 최종 test로 방법이나 checkpoint를 고르지 않고, validation에서 선정한 뒤 고정된 test로 확인하는 방식으로 진행 부탁드립니다.

상세 목표와 점검 항목, 최종 제출물은 EXPERIMENTS.md에 정리했습니다. 현재 GPU PPO 통합과 장기 학습은 미검증 상태이니 짧은 통합 확인부터 부탁드리고, 목표 달성이 어렵거나 설정에 문제가 있으면 실제 결과와 함께 공유해 주세요!
