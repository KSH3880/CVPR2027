# 자연 WAIT/CLEAR → STACK 관측 검증

ms57 설정을 재사용해 조건당 256개 에피소드를 처음부터 실행했다. 저장 상태 복원·bootstrap·rehearsal은 끄고, 단계 진입 조건·목표·경로 생성·체크포인트는 유지했다. 변경은 독립 검증 프로세스의 신체 관측 함수에만 적용했다. koo_cvpr 외부 소스와 기존 학습/뷰어 소스는 수정하지 않았다.

| ms57 관측 조건 | 자연 STACK 진입 | STACK 이후 넘어짐 판정 종료 | STACK 시간 초과 | 적층 성공 |
|---|---:|---:|---:|---:|
| 기존 캐시 관측 | 16 | 16 | 0 | 0 |
| STACK에서만 실제 신체 관측 | 19 | 1 | 17 | 0 |
| 진행 중 모든 단계에서 실제 신체 관측 | 18 | 0 | 17 | 1 |
| 전환 전 실제 관측, STACK에서 캐시 관측 재도입 | 14 | 14 | 0 | 0 |

기존 조건의 STACK 이후 종료는 0.77~1.37초였다. STACK에서만 교정한 조건의 17건은 6초 STACK 제한까지 유지됐고, 나머지는 바닥 상자 이탈 1건·넘어짐 판정 1건이었다. 실제 관측을 계속 제공한 조건에서는 18건 중 1건이 적층에 성공했다. STACK에서 캐시를 다시 도입하면 14건 모두 넘어짐 판정이 재현됐다.

관측 오류가 자연 전환 직후 붕괴에 중요한 영향을 준다는 근거다. 관측 교정만으로 전체 적층을 완수하는 것은 확인되지 않았고, 다수는 STACK 완료 조건을 충족하지 못해 시간 초과했다. 45도 기울기 지표는 일시적인 자세 변화도 포함하므로 넘어짐 판정 종료와 구분한다.

ms18에서는 기존·STACK만 교정·STACK에서 캐시 재도입 조건에 자연 진입이 없었다. 모든 진행 단계 교정 조건만 자연 진입 1건이 확보됐다. ms18의 자연 전환 비교를 확정할 표본은 부족하다.

조건 사이에 최초 root·관절·상자·목표·경로·관측의 동일성을 검사했다. 물리 시뮬레이션의 순차 실행에서는 전환에 도달하는 에피소드가 달라졌다. 동일 STACK 상태의 일대일 비교 또는 여러 학습 시드의 성공률 평가로 해석하지 않는다.
