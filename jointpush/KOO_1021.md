## 실행

프로젝트 루트에서 실행한다. 기본 conda는 `tokenhsi_juan`이며 `KOO_PYTHON`으로 Python 경로를 바꿀 수 있다.

```bash
# checkpoint 없이 소스·데이터·설정 CPU 검사
bash jointpush/scripts/koo_1021_prepare.sh
# 업로드 후 CPU contract 검사
bash jointpush/scripts/koo_1021_prepare.sh --checkpoint jointpush/checkpoints/koo_1021/Stage1BasePush.pth
# headless 평가
TOKENHSI_GPU=5 bash jointpush/scripts/koo_1021_test.sh
# 로컬 viewer
TOKENHSI_GPU=5 HEADLESS=0 bash jointpush/scripts/koo_1021_test.sh
# 서버 noVNC viewer
TOKENHSI_GPU=5 PORT=6086 bash jointpush/scripts/koo_1021_vnc.sh
# 같은 Stage1 학습 재개: optimizer/epoch/frame 포함, 2048환경
TOKENHSI_GPU=5 bash jointpush/scripts/koo_1021_train.sh
```

학습 wrapper는 기본적으로 점유 GPU 시작을 거부한다. 명시적으로 `KOO_ALLOW_SHARED_MPS=1`을 주면 여유32GiB 이상·기존 Python client1개·MPS server1개·검증된 MPS pipe 연결 조건에서만 공유 학습을 허용한다. MPS 자동 탐색과 viewer native 경로도 유지하며 MPS daemon을 시작/종료하지 않는다. 실행 전 실제 GPU 점유와 viewer 병행 조건을 다시 확인한다. 학습 명령은 Stage1 resume이며 Stage2 학습 명령이 아니다.

산출물은 `runs/jointpush/koo_1021/` 아래에 저장한다. 원본 script의 output 제한을 서버에 맞추기 위해 **로컬 runtime wrapper에서만** output 허용 경로를 이 디렉터리로 바꾼다. 원본 source는 manifest로 검사한다.

현재 checkpoint가 없어 model strict restore/정책 rollout/GPU·GUI는 미검증이다.
