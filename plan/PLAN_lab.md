# lab 큐

lab은 steer·ma에 속하지 않는 짧은 프로브, 인프라 검증, 처리량 측정을 넣는 기타 큐다.
고정 연구 단계나 장기 계획을 두지 않고 질문이 끝나면 다시 비운다.

공통 실험 설계와 GPU 배치는 [전체 PLAN](PLAN.md), 완료 기록은
[AUTO_RESULTS](../experiments/AUTO_RESULTS_lab.md), 검토된 결론은
[EXPERIMENTS](../experiments/EXPERIMENTS_lab.md)를 따른다.

## 사용 규칙

- 결과를 읽고 필요한 행을 한 줄씩 추가한다.
- 여러 축을 곱하지 않고 앞 결과에 따라 다음 축을 정한다.
- 경고 탐지에는 실패해야 통과하는 양성 대조군을 포함한다.
- 처리량 비교에는 당시 GPU 동거와 메모리 조건을 함께 기록한다.
- 결과는 steer·ma 설계 또는 공통 실행 레시피로 승격하고 lab은 다시 비운다.
- 의도적 비정상 종료만 `QUEUE_EXPECT_RC=<코드>`를 사용한다.

## 활성 큐

사용자는 `tag`, 질문, 환경변수와 행 순서를 관리한다. 자동화는 3열 `상태/GPU`와 완료 행만 관리한다.
4열에는 lab 기본 프로필과 다른 값만 적는다.
