# PUSH 원본 RSI·가변 정육면체

`stage1_v2_fixed_push_360_raw` 전용 설정으로 추가했다. 기존 PUSH/360 설정·checkpoint의 기본 동작은 유지한다.

- RSI는 기존7개 원본 clip·11개 후보 시각을 사용한다. 관절·손 높이·속도와 AMP 이력에 팔 높이 보정을 적용하지 않는다.
- `contact_mode: face_xy`는 양손 각각에서 같은 지정 면의 월드 XY 투영까지 거리를 계산한다. 면 폭 바깥에서는 가장자리까지의 거리도 포함하고, 더 먼 손의 거리 `d`로 상태 점수 `exp(-10*d*d)`를 계산한다. 손 중점·기준 높이·높이 허용폭·높이 감점을 사용하지 않는다. 기울어진 면은 유한 사각형을 XY에 투영하고 손 Z는 계산에 사용하지 않는다.
- 유효 접촉은 양손 각각의 면 XY 거리≤0.18m·각 손의 면 법선 반력≥0.5N·상자의 안쪽 법선 합력≥0.5N으로 판정한다. 제어 step 내 물리 tick의 OR 집계는 유지한다. state와 유효 접촉 모두 중점/높이 조건이 없다.
- 접촉 면은 기존 상자 로컬−Y 면을 유지하고 상자 회전을 따라간다. 현재 목표 방향의60도 후보 필터나 매 step 면 재선택은 사용하지 않는다. 접근/AT 보상·성공 시 포화·공유 비율·AMP는 유지한다.
- 정육면체 한 변1.2~1.7m를 환경 생성 시 상자마다 연속 균등 샘플링한다. 질량은 `12 + 8 × (한 변 길이 − 1.2) / 0.5`kg으로 선형 대응한다(1.2m→12kg, 1.45m→16kg, 1.7m→20kg). 크기/질량은 actor 수명 동안 고정한다.
- PUSH 담당 상자만 하나의 강체·두 충돌 형상으로 구성한다. 본체 마찰0.9, 밑판 마찰0.3·두께1cm이며 밑판 가로/세로는 상자와 같다(`inset: 0.0`). 본체 하단1cm를 판으로 대체해 외곽 크기·접지 높이·중심·질량·균일 정육면체 관성을 유지한다. 판은 상자와 함께 회전하며 추가 관절/강체는 없다. 땅의 정지/동마찰1.0, 사람과 기존 과제의 상자는 변경하지 않는다.
- 원본 `create_box`의 단일 충돌 형상은 이전 checkpoint용으로 유지한다. 판 형상 URDF는 실행 출력 아래 `push_assets/`에 생성한다. 물리 검사에서 판0.3의 감속 기반 실효 마찰은약0.64였다. 설정 계수와 실제 접촉 마찰은 구분한다.
- 상자 중심 높이·미는 면·장면 간격은 실제 크기로 계산한다. 접촉 RSI의 손 중점6cm 정렬 후, 사람의 모든 sphere/capsule/발 mesh가 지정 면 바깥에 최소5mm 떨어지도록 필요한 경우에만 전신을 수평 후퇴시킨다. 관절·높이·속도는 변경하지 않는다.
- 모든 충돌 형상이 미는 면 바깥 반공간에 있으면 상자 내부와 교차하지 않는다. 면 기준의 support 계산은 폭·높이와 무관하므로 사용 중인11개 후보의 초기 침투 방지는1.2~1.7m 연속 크기 범위에 적용된다.
- 기존/PUSH50:50·teacher KL·AMP·보행/목표 커리큘럼은 유지한다. 원본 NPY와 기존 공용 RSI cache는 변경하지 않으며 새 bank는 후보 시각과 물성 계약을 별도로 기록한다.

기본 전이는 `output/stage1/Stage1V2Fixed_00078000.pth`이며 `STAGE1_CHECKPOINT`로 변경한다. 새 raw 모델 재개는 `RESUME_CHECKPOINT`를 사용한다. 전이는 모델/정규화를 가져오고 optimizer/epoch을 새로 시작한다. 새 보상과 물성은 config에 저장되며, 기존 checkpoint의 재개/평가는 저장된 이전 설정을 유지한다. `PUSH_CHECKPOINT` 전이는 같은 원본 teacher·같은 본체 마찰의 모델에만 허용한다. 기존 고정 크기 checkpoint를 raw wrapper의 재개/추론에 직접 넣으면 거부한다. 새 물성은 `push_raw_cube120to170_mass12to20_linear_plate09_03_full_bank.json`에 기록하며 이전 bank는 보존한다. 실행 명령은 [config](../config.md), 추가 옵션은 [USAGE](../USAGE.md#push-원본-rsi가변-정육면체)를 따른다.

## 직육면체 variant

`stage1_v2_fixed_push_360_raw_cuboid`는 기존 raw와 분리한 설정이다. X는1.2~1.7m, Y/Z는각각1.45~1.7m에서 샘플링한 뒤 두 값 중 큰 값을Y에 배치해 Y≥Z를 보장한다. Y/Z의 최종 주변분포는 정렬의 영향을 받는다.

질량은 부피V에 따라 `15 + 5 × (V − 2.523) / (4.913 − 2.523)`kg으로 대응한다. 최소 크기(1.2,1.45,1.45)m는15kg, 최대(1.7,1.7,1.7)m는20kg이다. 본체0.9·밑판0.3/1cm/전체 폭·ground1.0과 원본 RSI/AMP/접촉 보상은 유지하고 PUSH만1200step(40초), 기존 과제는600step이다.

직육면체 bank는 기존 clip·후보 시각을 재사용하며 새로운 자세별 RSI screening 결과를 의미하지 않는다. 기본 전이는 fixed78000이고, 기존 raw를 재개하면 기존 크기/질량/에피소드 설정이 복원된다. 새 설정으로 전이하려면 전용 train wrapper의 새 학습 또는 명시적 warm-start를 사용한다.

아래는2026-10-20의 이전25~30kg·중점/높이 보상 설정에 대한 검증이다. 12~20kg 선형 질량과 면 XY 보상의 검증은 [changelog](../../changelog.md)의2026-10-21 항목을 따른다.

- 관련 CPU47개 통과. 크기/질량 범위·독립 샘플링·1.04m 기준점·최소 후퇴·전이/재개 계약을 검사했다.
- 실제 관절 FK로51개 크기(1cm 간격)×11후보×질량25/27.5/30kg=1683건과 연속 무작위365건을 검사했다. 초기 침투0/2048, 최소 면 여유 약5.00mm, 추가 후퇴 최대6.784mm였다.
- 같은2048건의 별도 GPU PhysX에서 원본 초기 속도·원래 humanoid/상자·동일 물리 파라미터로 최초 관절각을 PD 목표로 고정해1초 관측했다. 머리 접촉 충격0N·2m/s 초과0건·최대 상자 속도0.236m/s·최대 기울기0.740도였다. 질량 실측 최대 오차는약0.000006kg였다.
- 기존 PUSH11000에서 실제2048환경 짧은 학습을 실행해 epoch2/frame262144 저장, 모델·542개 로그 scalar finite와 정책/AMP 입력 정규화 불변을 확인했다. 본학습은 시작하지 않았다.
- 새 checkpoint의 실제1환경 추론64회·128쌍에서 초기 침투0, 머리 충격0N, 초기0.1초2m/s 초과0건, 최대 상자 기울기3.964도를 확인했다. 초기0.1초 최대 속도는1.803m/s였다. 원본 관절·속도·손 높이·AMP 이력, simulator 질량·마찰·접촉점 높이도 별도로 확인했다.
- 기존 checkpoint의 기본 보정 reset은 이전 root·관절·속도·상자·goal·후보 시각과 bitwise 동일했다. VNC wrapper 인자 전달과4환경 배치를 검사했으며 이번 작업에서 GUI viewer는 실행하지 않았다.

이 검증은 초기 침투와 짧은 물리 안정성 검사다. 장기 정책의 밀기 성공·전도 방지나 모든 반복 reset 이력의 무충격을 보장하는 평가는 아니다.
