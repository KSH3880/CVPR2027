# 비교 정책 참조 소스

현재 ENABLING 탐색에서 외부 경로로 참조하는 FSM/SCT 어댑터와 TokenHSI 관련 소스11개의 원본 스냅샷이다. [manifest.json](manifest.json)에 원본 경로·파일 SHA256·원본 HEAD가 있다. 파일은 내용 수정 없이 복사했으며 원본 라이선스/출처는 그대로 적용된다.

이 디렉터리는 실행 import 대상으로 연결하지 않았다. 실행 중인 탐색은 기존 외부 코드 트리를 계속 사용한다. 독립 실행 패키지가 아니며 가중치·데이터·SDK·모든 전이 의존성을 포함하지 않는다. 실행 환경과 요구사항, GitHub 공유 절차는 [가이드](../../../../markdowns/ENABLING_SEARCH_GITHUB.md)를 따른다.
